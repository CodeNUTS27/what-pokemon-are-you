# What Pokémon Are You? 🔮

A personality quiz built with **Vanilla JavaScript + ES6** that matches you to a Pokémon based on your traits.

## Features
- 🎯 **10 personalized questions** about your personality
- 📊 **4 trait categories**: Brave, Calm, Clever, Playful
- 🎨 **Smooth animations** with pure CSS
- 📱 **Responsive design** — works on desktop and mobile
- 🔄 **Instant retake** — restart the quiz anytime

## How It Works
1. Answer 10 simple personality questions
2. Get matched to one of 40 Pokémon (Gen 1-3)
3. See your trait breakdown and Pokémon's personality description

## Tech Stack
- **Vanilla JavaScript** (ES6+)
- **HTML5 & CSS3**
- **No frameworks** — pure browser APIs
